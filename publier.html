1 · Connexion à ton site

Pour publier d'un seul bouton, l'outil a besoin d'une clé GitHub (un « jeton »). Elle reste uniquement sur ce téléphone.

Comment créer le jeton (une seule fois)
  1. Ouvre GitHub, puis ton profil (en haut) → Settings.
  2. En bas du menu : Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Nom : « Inkyo publier ». Durée : 90 jours (ou plus).
  4. Repository access → Only select repositories → choisis Inkyo-view2.
  5. Permissions → Repository permissions → Contents → Read and write.
  6. Generate token, copie-le (il commence par github_pat_) et colle-le ci-dessous.

Ne le partage jamais. Tu peux le supprimer sur GitHub quand tu veux.
